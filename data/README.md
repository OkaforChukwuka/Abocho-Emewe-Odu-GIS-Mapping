# Data

This folder contains documentation relating to the datasets used in the project.

## Data Sources

Administrative boundary data was obtained from:

- **geoBoundaries**
- **GRID3 Nigeria, 2022**

Datasets used:

- Nigeria ADM1 — State boundaries
- Nigeria ADM2 — Local Government Area boundaries

Source:
https://www.geoboundaries.org/

The original datasets are not included in this repository.
